      Privacy & Architecture

      Why Choose VaaniSnap?

      Traditional translation apps push your audio to third-party cloud servers, charge monthly subscriptions, or monetize your private conversations. VaaniSnap is engineered to run locally on your device with complete privacy.

      Architecture Dimension Traditional Cloud Translators VaaniSnap (Our Solution)
      Processing Location Remote Cloud Servers (Audio streamed to third-party providers) ✓ On-Device Engine (Google ML Kit on-device models)
      User Privacy & Audio Server Upload (Transcripts stored on remote databases) ✓ 100% Volatile RAM (Disappears when session ends, 0 logs)
      Offline Capability Fails when WiFi or cellular data is unavailable ✓ 100% Offline (Once ~30MB model is saved locally)
      Licensing & Source Proprietary closed-source SaaS ✓ Apache 2.0 Open Source (Auditable on GitHub)
      Voice Playback (TTS) Paid cloud speech synthesize endpoints ✓ Android & Web Speech (Native hardware synthesis)
      End-to-End Pipeline

      System Architecture & Flow

      Designed cleanly around lifecycle-safe interfaces, isolating speech recognition, ML Kit translation, and TTS playback behind decoupled gateways.

      1. Voice Input Microphone capture with real-time decibel (rmsDb) feedback.
      ➔
      2. SpeechRecognizer Streams interim results into volatile RAM on the main thread.
      ➔
      3. Google ML Kit Translates on-device without remote cloud dependencies.
      ➔
      4. Native TTS Reads translation aloud in target dialect with play/stop toggle.

      Core Capabilities

      Built for Performance & Privacy

      Engineered natively with modern Jetpack Compose for Android and progressive web standards for browsers.

      Real-Time Speech Stream

      Streams words as you speak them. Four dynamic equalizer bars respond dynamically to your vocal decibels (rmsDb) with zero UI freezing.

      100% Volatile Memory

      Zero database, zero local tracking files, zero analytics. Your speech stays strictly in volatile RAM and is completely wiped when you close or refresh.

      Instant Bidirectional Swap

      Reverse languages with one tap (⇄). The active translated response automatically inverts into the new source and re-translates without needing you to speak again.
